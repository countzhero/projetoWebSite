<h2> Plataforma Inteligente para Gestão de Academias </h2>

A Plataforma Inteligente para Gestão de Academias tem como objetivo otimizar a
utilização dos equipamentos, reduzir filas, melhorar a experiência dos alunos e
fornecer dados estratégicos para a gestão da academia.

A solução proposta é uma plataforma integrada composta por aplicativo para os
alunos, painéis administrativos e dispositivos nos equipamentos. O sistema permitirá
check-in, visualização do mapa da academia, reservas, acompanhamento do treino,
controle de filas, notificações e indicadores para professores e gestores.
